# Coverage ownership reconciliation

Baseline: the previously verified complete run (3,231 tests), before removing the global reports module. `coverage-baseline.json` retains sanitized suite identities and the 1,148 class-level LINE counters from its original JaCoCo XML, with both original hashes. No baseline coverage values are invented or regenerated against changed code.

`coverage_ownership.py` maps each original report class, including nested classes, to its exact new package using the relocation manifest. Every counted old report must be mapped; otherwise comparison fails. Non-report classes retain their identity. Module/layer nonregression therefore compares the same existing classes under their new ownership. Every relocated class additionally has its own nonregression gate, preventing improvement elsewhere in a module from hiding a moved report's regression.

Three classes split across two modules. Arbitrarily assigning their old covered and missed lines to one destination would distort the module baseline. Each original split class and all its explicit successors are therefore compared as one strict family. These classes are excluded symmetrically from module-only groups on both sides, but ALL counters remain in the global layer thresholds and family nonregression checks. Missing family members fail closed. This is a change of comparison identity, not a coverage waiver.

All class LINE counters are conserved (13,842 covered / 2,529 missed in this baseline). Global layer gates retain the original JaCoCo package counters (13,839 covered / 2,529 missed), because source lines shared by nested classes are de-duplicated at package level. Ownership groups use class counters consistently on both sides. Comparisons multiply exact integer fractions; rounded display percentages never decide pass/fail. Existing aggregate thresholds remain strictly above domain 90%, application 80%, infrastructure 60%; complete discovery, zero failures/errors/skips remain required. Neither removed `reports` groups nor low-coverage split classes silently disappear.
